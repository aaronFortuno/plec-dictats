# Icones Lucide

SVG originals de [Lucide](https://lucide.dev/), descarregats del [repositori oficial](https://github.com/lucide-icons/lucide/tree/main/icons) el 23 d’octubre de 2026.

La llicència original es conserva íntegra a `LICENSE` (ISC i avís MIT per a les icones derivades de Feather). Les icones es carreguen localment, sense serveis externs.

`node tools/build-icons.cjs` reconstrueix `icons.js` amb aquest subconjunt de SVG. El símbol de marca de Plec i els esquemes dels plecs són dibuixos propis.
