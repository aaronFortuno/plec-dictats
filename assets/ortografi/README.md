# ortogra.fi

Símbol de la «o» accentuada, compartit amb el projecte pare [ortogra.fi](https://ortogra.fi/).

Font de la marca i guia d’ús: [aaronFortuno/ortogra-fi · assets/brand](https://github.com/aaronFortuno/ortogra-fi/tree/main/assets/brand). Llicència MIT.

El peu utilitza la versió SVG en línia, amb `currentColor` i `var(--accent)`, perquè s’adapti als temes clar i fosc sense cap petició externa.
